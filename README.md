# Travel Companion 

Travel Companion is a full-stack travel guide built with React, Firebase, Express, and external travel APIs.

The application allows users to:
-Search weather information for cities
-View country information
-Search flights
-Search hotels
-View maps and travel insights


# Features

## Authentication
Firebase Google Authentication
Protected routes for authenticated users
Login and registration pages


## Weather Information
Uses the OpenWeather API to:
Display current weather
Show temperatures and conditions
Provide travel weather insights

## Flight Search
Integrated with the Duffel API to:
Search flights between airports
Display airline information
Show departure details
Display pricing information

## Hotel Search

Integrated with Booking.com API (via RapidAPI) to:

Search hotel destinations
Generate booking links
Display hotel location information
